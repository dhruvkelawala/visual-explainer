# T3 visual pages

In T3 Code, a page is shown in the thread as a T3 visual page. `html_preview` checks it, and `html_render` shows it above your reply. The reader sees it on a desktop or a phone without opening a browser.

## When

Use this path when the `html_preview` and `html_render` tools exist. Open no browser, and reply with no local file path or `localhost` link. The rendered page stays in the thread. Write a copy to `~/.agent/diagrams/` only when the user asks for a file.

These are not T3 visual pages yet, because `html_render` rejects their viewport units: slide decks, plan pages (they also need the response round trip) and quick pages. In T3, write them to a file as before, and say that the page opens outside T3. A video is an MP4, not a page.

## Steps

1. Build the page from `templates/field-guide.html`. Keep its first `<head>` script and its `T3 VISUAL PAGE` CSS block as they are.
2. Run `html_preview` with `appearance:"light"` at width 728, then with `appearance:"dark"` at 728 and at 390 (a phone). Fix every console error, clipped label and horizontal scroll, then preview again.
3. Run `html_render` with a short `title`, and set `height` to the `contentHeight` of the 728 preview.
4. In the final reply, do not announce the page, say where it is or restate it. Add only what the page does not say.

## How the template fits T3

T3 adds a `<style id="t3-theme">` at the top of `<head>` and frames the page on the thread's background. The frame is 728px wide on a desktop and about 360px on a phone. The template's head script finds that style and adds the `t3` class to `<html>`. The `T3 VISUAL PAGE` CSS block then:

- leaves `body` with no background, so the thread shows through;
- hides the fixed Light/Dark switch;
- removes the left padding, so the page's left edge lines up with the reply text, and keeps 12px on the right for the hard shadows;
- keeps 16–32px of padding inside the inverse and cobalt colour fields.

## Rules from html_render

- Use no `vh`, `svh`, `lvh` or `dvh` units, and no `height:100%` on `html` or `body`. The frame grows to fit the page, so a height that follows the viewport grows without end. Both tools reject these units.
- Leave out `position:fixed` and `position:sticky`. The frame is as tall as the page, so a sticky table of contents never sticks.
- Give charts fixed pixel heights.
- Give a box with its own ground at least 16px of padding on every side. Field Guide keeps its square corners.
- Keep the page under 512,000 characters. Fonts and libraries load from their CDN. Local images written as absolute paths are inlined.
- A link to an `http(s)` page opens in T3's browser. Local paths and `localhost` links do not open.
